## Scenarios to inspect

- Search: blank queries, mixed case, duplicate parameters, invalid pagination, stable ordering, pagination beyond the end.
- Validation: malformed JSON, null/array payloads, oversized multibyte bodies, unknown fields, unsupported content type, invalid UTF-8.
- Authentication: missing/malformed credentials, wrong tokens, authenticated create/delete, unauthenticated health check, secret leakage and startup without configuration.

Measure actual findings, false positives, useful fixes, review latency, repeated comments, and missed issues. A clean review alone does not establish correctness.
